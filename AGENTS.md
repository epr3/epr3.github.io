## Agent skills

- Context: in-repo
- Issues: local Markdown in `.scratch/` — see `docs/agents/issue-tracker.md`
- Triage: none
- Layout: single-context

## Commit style

Use Conventional Commit subjects: `<type>(<optional scope>): <concise imperative summary>`. The established types are `feat`, `fix`, and `chore`; use the `deps` scope for dependency updates (for example, `fix(deps): update Astro to v6`). Keep the subject lowercase, with no trailing period. Include a PR reference only when one exists (for example, `(#26)`).
